# Support

Runrate is early OSS. The fastest way to get useful help is to include enough detail for someone else to reproduce the behavior without seeing your private logs.

## Good Support Requests

Include:

- Runrate version
- operating system
- Node version
- command you ran
- provider/adapter, such as Codex or Claude Code
- pricing mode
- expected total and actual total, if relevant
- a small redacted fixture when parser behavior is involved

Do not paste private prompts, secrets, API keys, private repo names, full raw provider logs, or sensitive file paths into public issues.

## Where To Ask

- Bugs: https://github.com/crup/runrate/issues/new?template=bug_report.yml
- Features: https://github.com/crup/runrate/issues/new?template=feature_request.yml
- Adapter requests: https://github.com/crup/runrate/issues/new?template=adapter_request.yml
- Security: see [SECURITY.md](SECURITY.md)
