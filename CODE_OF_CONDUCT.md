# Code of Conduct

Runrate should be a useful, low-drama place to improve local AI usage tooling.

## Expected Behavior

- Be direct, respectful, and specific.
- Assume contributors are here to improve the project.
- Keep feedback focused on the code, docs, tests, and user impact.
- Be careful with private usage logs, prompts, file paths, repo names, API keys, and other sensitive data.
- Help new contributors understand the project constraints before asking them to rewrite work.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing someone else's private data, logs, prompts, credentials, or workspace details.
- Repeated low-signal comments that derail issues or pull requests.
- Bad-faith reports, spam, or abuse of project communication channels.

## Reporting

For conduct or security-sensitive reports, email `connect@rajender.pro`.

For normal bugs and feature requests, use GitHub issues.

## Enforcement

Maintainers may edit or remove comments, close issues or pull requests, block users, or take other reasonable moderation actions to keep the project productive and safe.
